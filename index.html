Guia de utilização do Git

Configurar o Git Bash

Depois de ter instalado o Git no computador, abra o terminal Git Bash. Antes de começar a trabalhar nos seus projetos, vai ter de configurar a sua identidade para que o Git saiba quem está a fazer as alterações:

1. Definir o teu nome de utilizador:

git config --global user.name "O Teu Nome"

2. Definir o teu email:

git config --global user.email "teu@email.com"

3. Confirmar se ficou tudo bem guardado:

git config --list
