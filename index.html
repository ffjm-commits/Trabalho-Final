Guia de utilização do Git

Configurar o Git Bash

Depois de ter instalado o Git no computador, abre o terminal Git Bash. Antes de começar a trabalhar nos teus projetos, vais ter de configurar a tua identidade para que o Git saiba quem está a fazer as alterações:

1. Definir o teu nome de utilizador:

git config --global user.name "O Teu Nome"

2. Definir o teu email:

git config --global user.email "teu@email.com"

3. Confirmar se ficou tudo bem guardado:

git config --list

Guardar alterações num projeto

Com o Git Bash configurado, entra na pasta do teu projeto e usa estes comandos para começar a guardar versões:

1. Iniciar o Git na pasta do projeto:

git init

2. Preparar todos os ficheiros alterados:

git add .

3. Guardar as alterações com uma descrição:

git commit -m "O que foi feito"

4. Enviar o código para o GitHub (se tiveres repositório ligado):

git push
